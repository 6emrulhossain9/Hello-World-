## 🚀 Running the examples

Each file is standalone. Here are quick-start commands for a few of the more popular ones:

```bash
# C
gcc helloworld(C).c && ./a.out

# C++
g++ helloworld(C++).cpp && ./a.out

# Python
python3 helloworld(Python).py

# Java
javac helloworld(Java).java && java HelloWorld

# Go
go run helloworld(Go).go

# Rust
rustc helloworld(Rust).rs && ./helloworld

# bash
bash helloworld(bash).sh

# Javascript (Node)
node helloworld(Javascript).js
```

> Most files print `Hello World!` (or an equivalent) when executed with their
> language's standard toolchain.
